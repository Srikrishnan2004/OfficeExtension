# DocLens – Word, Excel & PowerPoint Viewer for Chrome

Open `.docx`, `.xlsx` and `.pptx` files directly in Chrome. Rendering happens
entirely inside the extension; documents are never uploaded anywhere.

## Install (unpacked)

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select this folder.
4. Optional: on the DocLens card click **Details** and enable
   **Allow access to file URLs** to open documents from `file://` links.

## Ways to open a document

| How | What happens |
| --- | --- |
| Click a link ending in `.docx`/`.xlsx`/`.pptx`… | Navigation is redirected to the viewer (declarativeNetRequest rule). |
| A site sends the file as a download | Download is cancelled and the file opens in the viewer instead. |
| Right-click a document link → **Open in DocLens** | Opens in a new tab. |
| Toolbar icon → **Open a file…** | File picker, or drag & drop a file onto the viewer page. |

Both automatic behaviours can be switched off from the toolbar popup. The
viewer's **Download** button always saves the original file.

## Supported formats

| Type | Formats | Renderer |
| --- | --- | --- |
| Word | .docx .docm .dotx .dotm | [docx-preview](https://github.com/VolodymyrBaydalka/docxjs) 0.4.1 |
| Excel | .xlsx .xlsm .xlsb .xltx .xls .ods .csv .tsv | [SheetJS](https://sheetjs.com) 0.18.5 |
| PowerPoint | .pptx .pptm .ppsx .ppsm .potx | [pptx-preview](https://www.npmjs.com/package/pptx-preview) 1.0.7 |

Not supported: legacy binary `.doc` and `.ppt`, `.odt`, `.odp`, `.rtf` (the
viewer says so and offers the download).

## Word fidelity

Word rendering was checked side by side against Microsoft Word on real
documents (`tools/word-compare/`). On top of docx-preview, DocLens:

- paginates like Word: overflowing content flows onto new pages, tables
  split between rows, and rows break between paragraphs;
- applies Word's built-in defaults when a file omits them (space after
  8pt, 1.16 line spacing);
- uses Word's line-height model: "multiple" spacing scales the font's
  natural line height, and the paragraph mark only affects the last line;
- adds metric-similar fallbacks for missing fonts (e.g. Aptos → Calibri)
  instead of dropping to Times;
- lays tables out on their stored grid widths, draws VML horizontal rules,
  aligns list text to the hanging indent, and hyphenates only when the
  document asks for it.

`lib/docx-preview.min.js` carries one patch (marked at the top of the file):
default-style rules for runs and cells kept only the `p`/`table` part of their
selector, so Normal-style fonts never reached the text.

## Known limitations

- Word: page breaks can land a few lines away from Word's, mostly where Word
  auto-fits table columns differently. Text boxes and some fields are
  approximated.
- Excel: shows cell values, number formats, merges, column widths, hidden
  rows/columns, solid fills and hyperlinks. Fonts, borders, charts and
  conditional formatting are not drawn (SheetJS community edition). Large
  sheets load 1,000 rows at a time and show up to 500 columns.
- PowerPoint: static slides; animations and transitions are not played.
- Links that need a POST request or a one-time token can't be re-fetched after
  a download is intercepted. Turn off **Open Office downloads here** for such sites.
